Welcome To Our ERP Journey

ABC Holdings is moving to a robust new Enterprise Resource Planning (ERP) system to improve how we work together. ERP connects key functions like patient administration, finance and pharmacy into one integrated platform. This ultimately means fewer errors, faster processes and better patient outcomes. A brighter more connected future for ABC Holdings

Hello everyone, as you know ABC Holdings is committed to providing the best possible service. To help better this ABC Holdings is embarking on an exiting journey which is implementing a new Enterprise Resource Planning (ERP) System. This exciting new system will allow a transition from paper to Electronic Health Records (EHR). Think of this system as the new digitalized backbone of our entire organization as it will connect various departments throughout our organization into one.


The goal of this update is to give you better tools so that we can work together more effectively. The best place to start for grasping what lies ahead will be this website.
